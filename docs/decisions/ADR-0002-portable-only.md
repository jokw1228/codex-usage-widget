# ADR-0002: 배포물은 portable exe만 제공

## 상태

채택

## 맥락

초기 배포 대상은 Windows 사용자이며, 설치 과정 없이 바로 실행 가능한 형태가 적합하다. 인스톨러는 시작 메뉴 등록, 제거 프로그램, 설치 경로 선택 등의 장점이 있지만 초기 프로젝트에는 과하다.

## 결정

GitHub Releases에는 Windows portable exe만 업로드한다. 설치형 NSIS installer는 만들지 않는다.

## 결과

장점:

- 사용자가 파일 하나만 내려받아 실행할 수 있다.
- 배포와 테스트가 단순하다.
- 포트폴리오/프로토타입 단계에서 설명이 쉽다.

단점:

- 자동 업데이트, 시작 프로그램 등록, 제거 프로그램은 제공하지 않는다.
- SmartScreen 경고는 코드 서명 전까지 발생할 수 있다.
