# AI 협업 기록

## 사용한 방식

이 프로젝트는 Codex와 대화하면서 다음 과정을 거쳐 만들었다.

- 사용자 요구사항 정리
- 로컬 Codex app-server 프로토콜 탐색
- Electron 기반 위젯 구현
- 화면 캡처를 통한 UI 검증
- Windows portable exe 패키징
- GitHub 공개 배포 구조 정리

## 포트폴리오 관점

강조할 수 있는 지점:

- AI를 단순 코드 생성이 아니라 제품 요구사항 정리, 기술 검증, 배포 구조 설계에 사용했다.
- 공식 공개 API가 없는 상황에서 로컬 프로토콜을 검증하고 현실적인 제약을 문서화했다.
- 사용자 배포를 고려해 로그인 정보를 직접 다루지 않는 방향으로 보안 경계를 잡았다.
- 기능 구현 후 실제 화면 캡처와 packaged exe 실행까지 검증했다.
