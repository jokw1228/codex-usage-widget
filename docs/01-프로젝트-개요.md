# 프로젝트 개요

Codex Usage Widget은 Codex 사용량을 매번 앱 좌하단 메뉴에서 확인하지 않고, Windows 화면 위에 작게 띄워두기 위한 데스크톱 위젯이다.

## 목표

- Codex 5시간/주간 남은 사용량을 빠르게 확인한다.
- 창 테두리, 최소화/최대화 버튼 없이 화면 위에 얹히는 형태로 만든다.
- 다른 사용자에게 무료로 배포할 수 있는 portable exe를 제공한다.
- 포트폴리오에서 AI 활용 개발 사례로 설명 가능하도록 문서와 구조를 정리한다.

## 비목표

- ChatGPT 로그인 정보를 직접 받거나 저장하지 않는다.
- OpenAI 계정 토큰을 자체 서버로 보내지 않는다.
- Codex 사용량의 공식 대시보드를 대체하지 않는다.

## 현재 제약

사용량 데이터는 공개 OpenAI API가 아니라 로컬 Codex app-server의 내부 프로토콜을 사용한다. 따라서 Codex 쪽 프로토콜이 바뀌면 위젯도 수정해야 할 수 있다.
